# Poloko Beetle

Una mascota virtual 3D inspirada en un escarabajo, creada con JavaScript y Three.js.

## Características

- Escarabajo 3D animado en el navegador
- Interacción con botones: alimentar, acariciar y dormir
- HUD con estado emocional y energía
- Estética simple, brillante y amigable

## Requisitos

- Node.js 18+
- npm

## Instalación

```bash
npm install
```

## Ejecución

```bash
npm run dev
```

Luego abre la URL local que te muestre Vite en el navegador.

## Construcción para producción

```bash
npm run build
```

## Estructura

- `index.html` — página principal
- `src/main.js` — lógica del mundo 3D y la mascota
- `src/style.css` — estilos visuales

## Objetivo

Crear una pequeña mascota virtual que sea divertida, colorida y fácil de extender con más animaciones, sonidos o comportamientos.
